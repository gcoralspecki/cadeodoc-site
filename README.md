# Site do Cadê o Doc

As páginas públicas de <https://cadeodoc.com.br>.

Este repositório é **público de propósito**, e contém apenas o que já é para ser
lido por qualquer pessoa: a apresentação do produto, a Política de Privacidade e
os Termos de Serviço.

O motor do produto vive noutro lugar, num repositório privado. Nada de código,
credencial ou documento de cliente entra aqui.

## Como editar

A fonte destas páginas é a pasta `site/` do repositório do produto. Editar por
lá e copiar para cá evita que as duas versões passem a discordar.

O arquivo `CNAME` é o que amarra o domínio próprio ao GitHub Pages. Apagá-lo
derruba o endereço.
